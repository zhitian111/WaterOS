本章按工程组件树组织：每个一级组件对应独立子目录，子模块继续向下拆分至\code{api/}与\code{impl/}叶子。叙述以各组件源码与\code{docs/exports/}导出为准；双架构差异只在确有差异处对比，其余强调上层复用。

\section{内核集成：trap 与系统调用入口}

用户态运行路径上的异常、中断与系统调用并不落在单个\code{wateros-*} crate内，而是由组合层\code{os/src/trap\_handler.rs}在\code{task::init()}之后注册为架构trap handler，把\code{trap\_entry\_rust}交出的\code{TrapCause}分流到syscall、MM、task与platform子系统。下文各组件节只描述本crate提供的接口与实现；本节说明跨组件衔接。

架构层汇编在\code{platform-arch}各\code{impl-*}中保存\code{TrapContext}并进入Rust入口；组合层根据\code{TrapCause}处理三类热路径：

\begin{itemize}
  \item 用户态\syscall{ecall}：读取\code{syscall\_nr}与参数，调用\code{syscall::dispatch\_syscall\_from\_trap}写回\code{UserRet}；\syscall{execve}成功时不推进用户PC，其余syscall将PC前进\code{SYSCALL\_INSN\_BYTES}（当前为4）。
  \item 用户态页错误：先调用\code{mm::kernel\_mm::handle\_user\_page\_fault}尝试COW或lazy映射；失败则经\code{syscall::raise\_current\_signal}投递\code{SIGSEGV}（编号11）。
  \item 监督态定时器中断：重装下一次定时器（\code{TIMER\_REARM\_MS}与\code{kernel\_main}同语义），递增tick计数并调用\code{syscall::timer\_tick}触发\code{task::schedule\_tick}。
\end{itemize}

内核态不可恢复trap进入\code{fatal\_kernel\_trap}停机，避免\code{sret}回到损坏PC形成级联fault。用户态不可处理fault在记录诊断后调用\code{task::exit\_group\_current}结束进程组。

\begin{rustcode}
match trap_cause {
    TrapCause::Exception(Exception::UserEnvCall) => {
        let syscall_nr = cx.syscall_nr().raw();
        let syscall_ret = dispatch_syscall_from_trap(syscall_nr, cx.syscall_args());
        let exec_succeeded = syscall_nr ==
            <ActiveSyscallNumberTable as SyscallNumberTable>::EXEC.raw()
            && syscall_ret >= 0;
        if !exec_succeeded {
            cx.add_user_pc(SYSCALL_INSN_BYTES);
            cx.set_syscall_ret(UserRet(syscall_ret));
        }
    }
    TrapCause::Exception(Exception::LoadPageFault)
    | TrapCause::Exception(Exception::StorePageFault) => {
        if mm::kernel_mm::handle_user_page_fault(
            task::current_task_user_aspace_ptr(), cx.fault_addr(), fault_access) {
            return;
        }
        let _ = syscall::raise_current_signal(11);
    }
    TrapCause::Interrupt(Interrupt::SupervisiorTimer) => {
        // rearm timer, syscall::timer_tick(), task::schedule_tick()
    }
    // ...
}
\end{rustcode}
