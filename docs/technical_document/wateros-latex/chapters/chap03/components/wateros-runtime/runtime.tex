\section{wateros-runtime}

\code{wateros-runtime}聚合内核早期运行时能力：\code{panic}、\code{console}、\code{logging}、\code{heap\_allocator}，以及在\code{serial-uart-virt} feature下再导出\code{serial}。根crate只做模块再导出，初始化顺序由\code{wateros}组合层保证：任何堆分配前\code{heap\_allocator::init()}，使用\code{log!}前\code{logging::init()}，\code{klog::init()}与之独立。

QEMU主线默认\code{impl-platform-console}，把\code{print!}/\code{println!}接到\code{platform::console}；\code{impl-dummy}下任何实际写控制台会\code{unimplemented!()}。开发日志经\code{WaterOSLogger}着色上屏，不写入\code{wateros-klog}环；需要「上屏+进环」时调用方须分别使用\code{log::*!}与\code{klog\_*!}。日志级别由\code{impl-trace}…\code{impl-error} feature择一（多开时取最安静档）。
