\subsubsection{Console trait，api-v0}

\code{Console}为标记trait，约束实现须同时满足\code{core::fmt::Write}与\code{Default}。\code{write\_str}语义与\code{fmt::Write}一致；是否缓冲、如何换行由具体后端决定。v0未定义读侧能力，控制台输入不在本契约范围。后续版本若需\code{read}或行缓冲，应扩展新trait而非破坏现有\code{Console}默认方法。

\begin{rustcode}
pub trait Console: fmt::Write + Default {}
\end{rustcode}
