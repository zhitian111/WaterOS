\subsection{runtime-console}

\code{wateros-runtime-console}在\code{Console} trait之上提供\code{print}/\code{prints}、\code{write\_raw\_bytes}、\code{AnsiColor}着色与\code{show\_logo}横幅；\code{print!}/\code{println!}宏绑定当前feature选中的\code{ConsoleHandle}。\code{write\_raw\_bytes}面向非UTF-8或\syscall{write}等原始字节路径：无平台控制台时静默丢弃，避免无串口构建引入链接依赖。
