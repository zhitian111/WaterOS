\subsection{fs-api}

\code{fs-api}子树仅含\code{api-v0} crate（\code{wateros-fs-api-v0}）。聚合层以\code{pub mod api \{ pub use ::api\_v0::*; \}}重导出，供\code{wateros-fs}、\code{fs-impl-*}与各子系统共享同一契约面。本层不依赖具体块格式库或驱动实现。
