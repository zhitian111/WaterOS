\subsection{fs-rootfs}

\code{fs-rootfs}保存probe选定的活动\code{FsImpl}与当前根卷\code{SharedRwFs}句柄，并提供辅助RO/RW挂载入口。\code{mount\_generation}将根卷与辅助卷变更通知给VFS页缓存。聚合层\code{fs::init()}只调用\code{set\_active\_fs\_impl}；\code{mount\_default\_root\_rw}由bring-up总线在块设备与驱动就绪后调用。
