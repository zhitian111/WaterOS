\subsection{fs-impl}

\code{fs-impl}目录收纳块文件系统具体实现crate，不经独立聚合\code{lib.rs}导出，而是由\code{wateros-fs/src/lib.rs}按feature条件\code{use}并填入\code{registered\_fs\_impls()}。默认启用\code{impl-ext4-rs}与\code{impl-devfs}；\code{impl-ext4}为可选回退；\code{impl-dummy}仅为工作区占位。
