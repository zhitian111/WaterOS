\section{wateros-fs}

\code{wateros-fs}是块文件系统与伪文件系统的聚合层：对外经\code{fs::api}暴露\code{FsImpl}注册表与卷读写契约，经\code{fs::devfs}、\code{fs::procfs}、\code{fs::rootfs}分别提供设备节点、\code{/proc}视图与根卷句柄。启动期\code{fs::init()}刷新devfs、在默认根块设备上\code{probe}并注入活动\code{FsImpl}，但不挂载根卷；bring-up再调用\code{mount\_default\_root\_rw()}完成单一RW ext4根卷挂载。

默认feature为\code{api-v0} + \code{impl-devfs} + \code{impl-ext4-rs}；可选\code{impl-ext4}切换至ext4plus旧路径。syscall与VFS不直接依赖\code{fs-impl-*}，而是经\code{wateros-vfs}的\code{impl-fs-bridge}消费本组件聚合API。
