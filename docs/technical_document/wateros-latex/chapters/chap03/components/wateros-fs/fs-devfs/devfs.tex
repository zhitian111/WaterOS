\subsection{fs-devfs}

\code{fs-devfs}维护内核视角的设备节点表：将\code{wateros-driver}枚举的块/字符设备映射为\code{/dev/*}路径，供\code{fs::init()}解析默认根块设备、供VFS\code{open}字符设备节点。聚合\code{lib.rs}按feature选择\code{active\_impl}（默认\code{impl-kernel}），对外再导出\code{refresh}、\code{lookup\_block\_device}、\code{default\_root\_block\_path}、\code{list\_dev\_nodes}等便捷函数。
