\subsection{fs-procfs}

\code{fs-procfs}提供\code{/proc}伪文件系统的内容生成：按tid输出\code{status}、\code{maps}、\code{cmdline}等，并支持全局\code{meminfo}、\code{mounts}等节点。内容依赖\code{wateros-task}、\code{wateros-mm}快照及VFS注册的\code{argv}/\code{exe}/\code{mount}回调，api层本身不拉取这些依赖。
