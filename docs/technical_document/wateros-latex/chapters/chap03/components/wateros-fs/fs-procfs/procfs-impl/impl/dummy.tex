\subsubsection{impl-dummy}

\code{DummyProcFs}实现\code{ProcFsView}：\code{exists}恒\code{false}，\code{metadata}/\code{read}返回\code{NotFound}，\code{read\_dir}返回空表。回调注册函数\code{register\_*}为空操作。\code{view()}返回全局唯一静态实例。

用于无task/VFS回调的最小链接；不可满足依赖\code{/proc}内容的测例。与\code{impl-kernel}互斥由\code{fs-procfs} feature选择。
