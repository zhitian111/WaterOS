\subsection{platform-impl}

\code{platform-impl} crate按feature提供具体板级profile：引导参数类型化、\code{PlatformTimeImpl}频率回退、早期控制台、deadline定时器编程与系统复位。聚合层通过\code{active\_impl}别名选中\code{impl-qemu-riscv64-opensbi}、\code{impl-qemu-loongarch64-virt}或\code{impl-dummy}；必须与\code{platform-arch}侧ISA impl配对（RISC-V profile配\code{impl-riscv64}，LoongArch profile配\code{impl-loongarch64}）。

各profile把\code{api-v0} trait落实为OpenSBI调用、MMIO UART轮询、Constant Timer CSR写或ACPI GED寄存器写；不包含trap帧或页表格式实现。
