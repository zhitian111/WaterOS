\subsubsection{impl-dummy}

\code{impl-dummy}为全桩板级：控制台、定时器与复位调用一律返回\code{Unsupported}；\code{boot}路径上访问\code{arg0}等触发\code{unimplemented!()}。\code{PlatformTimeImpl}频率查询亦返回\code{Unsupported}。仅用于未绑定真实环境的编译占位，不得作为可启动内核配置。
