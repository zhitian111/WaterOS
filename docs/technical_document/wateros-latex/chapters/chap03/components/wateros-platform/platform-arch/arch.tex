\subsection{platform-arch}

\code{wateros-platform-arch}聚合\code{arch-api-v0}与按feature二选一挂载的\code{arch-impl-riscv64}/\code{arch-impl-loongarch64}。对外导出\code{time}、\code{task}、\code{trap}、\code{interrupt}与\code{paging}模块；\code{arch\_boot()}在启用对应impl时安装trap向量。\code{impl-riscv64}与\code{impl-loongarch64}不可同时启用，由\code{compile\_error!}守卫。

本crate只操作CPU可见的CSR与汇编约定，不经SBI写串口或编程固件定时器；trap业务路由经\code{kernel\_trap}注册到组合层，arch侧\code{trap\_entry\_rust}仅保存帧并调用\code{invoke\_kernel\_trap\_handler}。\code{paging}只负责地址空间token激活与TLB刷新，页表内容与PTE编码在\code{wateros-mm}。
