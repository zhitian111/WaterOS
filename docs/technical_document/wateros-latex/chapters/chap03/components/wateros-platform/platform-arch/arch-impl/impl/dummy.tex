\subsubsection{impl-dummy}

\code{arch-impl-dummy}仅保留占位算术\code{add}与单元测试，不实现\code{arch-api}要求的trap/分页/任务上下文类型，无法作为可启动内核的ISA后端。启用该feature时\code{arch\_boot}为空操作；与真实profile的切换完全由上层\code{wateros-platform}的\code{impl-qemu-*} feature决定，生产构建不应依赖本crate。
