\subsection{platform-api}

\code{wateros-platform-api-v0}定义与具体ISA/固件无关的板级契约：引导参数槽位、平台时间频率、deadline定时器、早期控制台与系统复位。聚合层\code{platform::boot}、\code{time}、\code{reset}、\code{console}在启用\code{api-v0} feature时再导出trait类型，并把\code{active\_impl}中的具体结构体别名为\code{BootArgs}/\code{PlatformTimeImpl}等；\code{timer}模块虽在根crate实现组合逻辑，但deadline语义仍依赖本crate的\code{PlatformDeadlineTimer}与\code{PlatformTimerDeadline}。
