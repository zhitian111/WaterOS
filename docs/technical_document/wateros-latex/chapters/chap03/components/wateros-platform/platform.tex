\section{wateros-platform}

\code{wateros-platform}把ISA相关原语与板级/QEMU环境能力收束为内核可直接调用的门面。聚合crate按feature同时选定\code{platform-arch}下的\code{impl-riscv64}或\code{impl-loongarch64}，以及\code{platform-impl}下的OpenSBI或LoongArch\code{virt} profile；在二者之上组合\code{timer}（arch tick + 平台Hz + deadline编程）、\code{time}（引导期频率缓存）、\code{wall\_clock}（单调纳秒与\code{CLOCK\_REALTIME}偏移）等语义，并向\code{wateros-runtime}、\code{wateros-mm}、\code{wateros-task}等上层提供trap帧、分页CSR、中断开关与早期控制台。

根crate不实现具体硬件访问：trap向量与帧布局在\code{arch-impl}，串口/SBI timer/复位在\code{platform-impl}，契约分别在\code{platform-api/api-v0}与\code{arch-api/api-v0}。组合层须在首次用户态trap前调用\code{platform::arch::init()}安装向量，并在\code{task::init}附近注册\code{kernel\_trap} handler；若已从DTB探测timebase，须在首次\code{timer}使用前调用\code{platform::time::set\_frequency\_hz}。
