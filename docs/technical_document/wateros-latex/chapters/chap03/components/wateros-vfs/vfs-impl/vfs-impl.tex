\subsection{vfs-impl}

\code{vfs-impl}目录收纳VFS后端与per-task会话实现，由\code{wateros-vfs/Cargo.toml} feature选用：\code{bridge-fs-api} 对应 \code{impl-fs-bridge}，含对 \code{impl-page-cache} 的依赖；\code{impl-fd-session} 对应 fd/cwd 表；\code{impl-dummy} 对应无存储占位。各crate实现\code{api-v0} trait的具体语义，聚合\code{active\_impl}在编译期选定\code{FsBridge}或\code{DummyBackend}。
