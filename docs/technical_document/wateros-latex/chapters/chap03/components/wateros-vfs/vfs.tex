\section{wateros-vfs}

\code{wateros-vfs}在syscall与\code{wateros-fs}之间叠加路径解析、挂载命名空间、页缓存与per-task fd语义。契约集中于\code{vfs-api/api-v0}；默认feature为\code{api-v0} + \code{bridge-fs-api} + \code{impl-fd-session}，\code{active\_impl::backend()}选中\code{impl-fs-bridge}的\code{FsBridge}。无\code{bridge-fs-api}时回退\code{impl-dummy}占位后端。

聚合层导出\code{vfs::root}（单根只读）、\code{vfs::mount}（RW会话）、\code{vfs::fd}/\code{vfs::cwd}（\code{per-task}状态）及大量以\code{\_absolute}结尾的路径级元数据操作函数；不re-export\code{wateros-fs}类型，跨层映射集中在\code{bridge}。
