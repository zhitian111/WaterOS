\subsection{vfs-api}

\code{vfs-api}仅含\code{api-v0} crate（\code{wateros-vfs-api-v0}）。聚合\code{wateros-vfs}以\code{pub use api\_v0 as api}重导出全部契约类型，并在此基础上组合\code{root}、\code{mount}、\code{self\_test}等门面模块。syscall与ABI层应只依赖\code{vfs::api}与聚合函数，避免直接引用\code{impl-*} crate。
