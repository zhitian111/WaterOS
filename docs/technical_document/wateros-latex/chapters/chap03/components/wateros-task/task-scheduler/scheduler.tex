\subsection{task-scheduler}

调度器子系统，经\code{active\_impl} feature 绑定具体算法，对外统一\code{scheduler::*}门面。\code{wateros-task}聚合层将\code{spawn}、\code{yield}、\code{wait}、\code{schedule\_tick}、trap 帧委托等薄封装转发至此。

与 impl-core 的边界：本 crate 维护当前任务、就绪/阻塞结构、等待队列与唤醒路径，调用 arch \code{\_\_switch}完成切换；TCB 内存布局与 trap 帧读写由\code{impl-core}提供，调度器只通过\code{TaskRegistry}操作任务对象。

\code{impl-multi-class}与\code{impl-round-robin}互斥；未启用任一实现时\code{compile\_error!}。默认使用\code{impl-multi-class}。
