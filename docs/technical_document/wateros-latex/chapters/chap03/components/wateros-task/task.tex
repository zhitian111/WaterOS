\section{任务管理组件}

任务组件\code{wateros-task}组合任务语义类型、按feature选定的控制块布局与调度算法，向上提供内核与用户任务创建、主动让出、fork与exec、等待与进程回收等稳定API。调度器决定何时运行谁，实现core决定单个任务长什么样；更换调度策略只改调度crate，更换控制块字段只改实现core。

内核在陷阱初始化与内存就绪后调用本组件初始化进程registry与调度器，随后进入首次任务切换。时钟tick驱动时间片轮转，阻塞与睡眠委托等待队列。fork与exec与内存组件协作获取新地址空间；陷阱返回路径在用户任务与架构陷阱处理之间同步陷阱帧。系统调用层映射Linux错误码并调用本组件聚合API，用户态返回值由ABI组件写入陷阱帧。

默认feature启用API契约、实现core与多类调度骨架；纯轮转实现与多类实现互斥，编译期强制二选一。bring-up期有效调度策略仍为OTHER类路径，FIFO与RR队列已有骨架但未完整抢占语义；当前为单核假设，无per-CPU就绪队列。

// task/lib.rs: fork 与内存组件协作
pub fn fork_current(
    child_stack: usize,
    new_aspace_ptr: usize,
    new_satp: usize,
) -> Option<TaskId> {
    // new_aspace_ptr / new_satp 由 mm::kernel_mm::fork_user_aspace 提供
    let parent_pid = current_process_task_snapshot().map(|task| task.pid)?;
    let child_id = scheduler::create_fork_child(child_stack, new_aspace_ptr, new_satp)?;
    active_impl::with_process_registry(|registry| {
        let _ = registry.create_process_like_fork(parent_pid, child_id, address_space);
    });
    scheduler::enqueue_ready_task(child_id);
    Some(child_id)
}
\end{rustcode}
