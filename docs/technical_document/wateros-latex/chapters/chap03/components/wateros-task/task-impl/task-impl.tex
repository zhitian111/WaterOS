\subsection{task-impl}

\code{wateros-task-impl-core}，feature \code{impl-core}，实现单任务内存表示与进程 registry。聚合层以\code{pub(crate) use impl\_core as active\_impl}绑定，对外再导出\code{TaskBootstrap}等 arch 入口所需类型。

调度器通过\code{TaskRegistry}持有\code{TaskControlBlock}指针，不定义 TCB 字段布局；registry 与\code{ProcessRegistry}分离，后者维护 PID/TID、进程组、rlimit、stopped/continued 状态机，不参与就绪队列决策。
