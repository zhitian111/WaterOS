\section{wateros-syscall}

\code{wateros-syscall}是用户态与内核子系统之间的最后一层门面：平台\code{trap}路径收集系统调用号与六个寄存器参数后，经本组件分发到各\code{sys\_*}实现，并把内部错误映射为Linux风格的\code{-errno}返回值。聚合\code{src/lib.rs}在\code{impl-kernel}启用时导出\code{dispatch\_syscall\_from\_trap}、信号/定时器协作钩子以及C ABI入口\code{\_\_wateros\_syscall\_dispatch\_current}；\code{api-v0}则提供与具体号表解耦的\code{SyscallKind}与\code{SyscallDispatcher}契约。

根\code{Cargo.toml}默认启用\code{impl-kernel}（隐含\code{api-v0}与\code{abi/api-v0}）。主线平台feature（\code{qemu-riscv64-opensbi}、\code{qemu-loongarch64-virt}）经根内核传递\code{abi/impl-linux-generic64}，使活跃号表为\code{LinuxGeneric64}。本组件依赖\code{wateros-abi}读取参数包与号表，并向下调用\code{wateros-vfs}、\code{wateros-mm}、\code{wateros-task}、\code{wateros-ipc}、\code{wateros-cred}、\code{wateros-klog}等稳定内核接口；\code{task}不反向依赖本组件。
