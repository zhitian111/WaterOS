\section{系统调用组件}

系统调用组件是用户态进入内核后的总接线板：陷阱路径把调用号和六个寄存器参数交进来，这里按 Linux 通用 64 位编号分派到文件、内存、任务、IPC 等子系统，并把内部错误收成负的\code{errno}返回值。同一层还导出定时器 tick、信号投递等与陷阱协作的钩子。

契约层描述有哪些语义槽位、默认未实现时返回什么；实现层持有按号分发表和各具体处理函数。号表里的常量只表示 ABI 对齐，是否与内核实现一一对应要分别核对。任务子系统不反向依赖本组件，保持依赖单向。

\begin{rustcode}
// trap 入口：SyscallArgs → 号表分发
pub fn dispatch_syscall_from_trap(syscall_nr: usize, syscall_args: SyscallArgs) -> isize {
    active_impl::dispatch_syscall_from_trap(syscall_nr, syscall_args)
}

// C ABI：汇编陷阱返回路径可直接调用
#[unsafe(no_mangle)]
pub extern "C" fn __wateros_syscall_dispatch_current(
    syscall_nr: usize, arg0: usize, /* arg1..arg5 */
) -> isize {
    let args = SyscallArgs::from_regs([arg0, arg1, arg2, arg3, arg4, arg5]);
    dispatch_syscall_from_trap(syscall_nr, args)
}
\end{rustcode}
