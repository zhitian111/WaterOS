\section{ABI组件}

\code{wateros-abi}定义用户态与内核共享的系统调用 ABI：Linux 风格错误码、六个寄存器参数包、调用号抽象与负\code{errno}返回值编码。聚合\code{src/lib.rs}按 feature 挂载版本化契约与具体号表实现；默认 feature 为空，调用方须显式启用契约层及目标平台号表，或仅链接占位桩做编译烟测。

主线平台 feature 经根内核传递 Linux 通用 64 位实现，同时启用契约与活跃号表类型别名。系统调用分发与平台陷阱路径通过本组件读取参数包与符号化调用号；号表中的常量只表示 ABI 约定，是否与内核处理函数一一对应由 syscall 实现层决定。契约按关注点拆为返回值编码、错误码枚举、调用号 trait 与 C 布局参数包等子模块，便于用户态桩代码与内核分发层共用同一套类型而不互相拖拽实现细节。

\begin{rustcode}
// abi/lib.rs: 号表 trait + 主线平台活跃别名（需 impl-linux-generic64）
pub mod syscall_number {
    pub use api_v0::syscall_number::{SyscallNumber, SyscallNumberTable};
    #[cfg(feature = "impl-linux-generic64")]
    pub use impl_linux_generic64::LinuxGeneric64 as ActiveSyscallNumberTable;
}
\end{rustcode}
