\section{工具组件}

\code{wateros-utils}预留给与平台弱耦合的通用小工具。\code{\#![no\_std]}，无\code{[dependencies]}，也没有\code{api/}/\code{impl/}子crate分层。当前对外仅导出占位函数，供crate内单测烟测；根\code{wateros}以\code{utils}别名默认依赖，但主线内核代码尚未消费其公共API。

\code{src/asm/riscv/print\_rigister.S}保留早期UART寄存器打印辅助，未编入现行构建。后续可在此集中纯函数或数据结构，并保持不反向依赖\code{wateros-base}等平台类型，以维持依赖DAG清晰。

// utils/lib.rs: 早期占位，不代表最终公共 API
