\subsection{ipc-pipe}

\code{ipc-pipe}在\code{feature pipe}下由父聚合导出\code{ipc::pipe::\{Pipe, PipeEndpoint, ...\}}。聚合\code{lib.rs}重导出\code{api-v0}契约类型，并在\code{impl-ringbuf}下将\code{impl\_ringbuf}选为\code{active\_impl}。syscall 经\syscall{pipe}/\syscall{pipe2}创建端点对；VFS fd 表持有\code{PipeEndpoint}，\code{dup}/\code{fork}通过引用计数实现 shell 管道式部分 close 语义。默认容量来自\code{wateros-base-config::ipc::DEFAULT\_PIPE\_CAPACITY}（4096 字节）。
