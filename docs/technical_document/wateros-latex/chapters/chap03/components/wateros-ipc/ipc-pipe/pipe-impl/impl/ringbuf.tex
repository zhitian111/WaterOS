\subsubsection{impl-ringbuf}

\paragraph{数据结构。}
\code{PipeState}在\code{spin::Mutex}保护下维护环形缓冲\code{buf}、\code{head}、\code{len}、读写端开关\code{read\_open}/\code{write\_open}，以及读/写 fd 引用计数\code{read\_refs}/\code{write\_refs}。引用归零时关闭对应方向并唤醒对端等待队列。

\begin{rustcode}
struct PipeState {
    buf: Vec<u8>,
    head: usize,
    len: usize,
    read_open: bool,
    write_open: bool,
    read_refs: usize,
    write_refs: usize,
}
\end{rustcode}

\code{Pipe}持有\code{state}与独立的\code{read\_wait}/\code{write\_wait}两个\code{WaitQueue}。阻塞读在空且写端仍开时于\code{read\_wait}条件等待；阻塞写在满且读端仍开时于\code{write\_wait}等待；\code{TaskWaitResult::Interrupted}映射为\code{PipeError::Interrupted}。

\paragraph{fd 端点。}
\code{PipeEndpoint}以\code{Arc<Pipe>}共享内核对象；\code{Clone}时调用\code{acquire\_read}/\code{acquire\_write}，\code{close}调用\code{release\_*}，从而实现 dup/fork 后部分 close 仍可读写的 shell 管道语义；\code{test()} 中有回归用例。

\paragraph{poll 与 resize。}
\code{poll\_revents\_read}/\code{poll\_revents\_write}按\code{POLLIN}/\code{POLLOUT}/\code{POLLHUP}/\code{POLLERR}位返回就绪状态；\code{poll\_wait\_*\_for\_ticks}在\code{still\_waiting}闭包为真时阻塞，供多 fd poll 重扫。\code{set\_capacity}仅在\code{len == 0}时替换底层\code{Vec}，对应\code{F\_SETPIPE\_SZ}子集。

\paragraph{限制。}
单 pipe 固定上限由创建时容量决定；无 splice/tee；全局 pipe 实例数无内核硬限制。
