\subsection{ipc-waitqueue}

\code{ipc-waitqueue}为 IPC 子系统提供与\code{wateros\_task}对齐的等待队列视图。默认\code{feature impl-task}将\code{wateros\_task::WaitQueue}薄包装为\code{WaitQueue}，供\code{ipc-pipe} 读写阻塞、\code{ipc-futex}，按 \code{FutexKey} 建队，等对象复用，避免 IPC 模块直接依赖 task 聚合 crate 的命名细节。语义完全委托底层：无限/超时等待、条件等待、\code{wake\_one}/\code{wake\_all}、\code{requeue\_to}与空队列\code{try\_release\_empty}回收\code{WaitQueueId}均与 task 层一致。
