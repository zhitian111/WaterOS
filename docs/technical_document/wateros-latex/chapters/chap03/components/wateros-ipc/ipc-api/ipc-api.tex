\subsection{ipc-api}

\code{ipc-api}目录下仅有\code{api-v0}子 crate（\code{wateros-ipc-api-v0}），无独立聚合\code{lib.rs}。父组件\code{wateros-ipc}以\code{pub mod api \{ pub use ::api\_v0::*; \}}重导出，供未来固化跨子系统 IPC 句柄、错误码与\code{repr(C)}布局。当前 crate 仅提供\code{add}占位函数与单元测试，不是正式 IPC 语义；pipe、futex、shm、signal 等真实契约位于各自子 crate 的\code{api-v0}。
