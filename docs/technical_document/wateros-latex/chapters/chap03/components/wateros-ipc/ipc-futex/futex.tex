\subsection{ipc-futex}

\code{ipc-futex}在\code{feature futex}下导出全局\code{FutexHub::global()}。聚合\code{lib.rs}优先选\code{impl-task}为\code{active\_impl}；仅启用\code{impl-dummy}且无\code{impl-task}时回退链接桩。syscall 层解码\code{futex(2)}操作码、访问用户 futex 字并构造条件闭包；本组件负责按\code{FutexKey}惰性建队、阻塞/唤醒、\code{requeue}迁移与 per-task robust 侧表，不直接读写用户内存。
