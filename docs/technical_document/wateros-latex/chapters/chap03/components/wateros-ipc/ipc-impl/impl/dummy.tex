\subsubsection{impl-dummy}

\code{wateros-ipc-impl-dummy}在\code{feature impl-dummy}下被父聚合选为\code{active\_impl}。实现与\code{wateros-ipc-api-v0}对称：导出\code{add}占位函数，不模拟 syscall、不管理资源生命周期。

\begin{rustcode}
/// 占位算术：满足链接与单测；不模拟任何 syscall 或资源生命周期。
#[inline]
pub fn add(left : u64, right : u64) -> u64 { left + right }
\end{rustcode}

\paragraph{feature 链。}
根\code{wateros-ipc}的\code{default}与\code{api-v0}均传递\code{impl-dummy} feature；替换为真实顶层 impl 时需保持\code{pub use ... as active\_impl}路径稳定，避免组合层大面积改动。当前无其它 impl 变体。
