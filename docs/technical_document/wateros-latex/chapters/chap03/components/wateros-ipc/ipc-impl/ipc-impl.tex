\subsection{ipc-impl}

\code{ipc-impl}承载聚合层\code{active\_impl}命名空间。父组件在\code{feature impl-dummy}下执行\code{pub use impl\_dummy as active\_impl}，与\code{ipc::api}占位对称，保证默认 feature 组合可链接、可单测。真实 IPC 路径由\code{ipc-pipe}、\code{ipc-futex}等子 crate 各自的\code{active\_impl}提供；顶层\code{ipc-impl}不参与 pipe 读写或 futex 唤醒。
