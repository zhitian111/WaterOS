\section{进程间通信组件}

进程间通信组件把等待队列、管道、futex、共享内存和信号收成一组可按 feature 打开的子能力。系统调用层负责 Linux 参数解码与错误码；虚拟文件系统给管道两端分配 fd；内存组件在共享段附着后完成用户映射；任务与陷阱路径配合完成可中断睡眠和信号投递。本组件不定义陷阱约定，只对外提供稳定门面。

主线启用完整 feature 后，管道走环形缓冲，futex 与调度协作，共享内存维护段注册表，信号区分进程级与线程级状态。等待队列语义委托任务子系统，避免 IPC 依赖方直接耦合调度内部结构。顶层占位实现仍只做链接自检，真实契约在各子 crate 内演进。

\begin{rustcode}
// ipc/lib.rs：默认 waitqueue；all 再挂 pipe / futex / shm / signal
#[cfg(feature = "pipe")]
pub mod pipe { pub use ::pipe::*; }
#[cfg(feature = "futex")]
pub mod futex { pub use ::futex::*; }
#[cfg(feature = "shm")]
pub mod shm { pub use ::shm::*; }
#[cfg(feature = "signal")]
pub mod signal { pub use ::signal::*; }
pub mod waitqueue { pub use ::waitqueue::*; }
\end{rustcode}
