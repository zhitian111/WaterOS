\section{wateros-klog}

\code{wateros-klog}维护内核可查询消息环，与\code{wateros-runtime}控制台日志低耦合。内核与其它组件经\code{record}/\code{klog\_*!}宏写入；用户态经\syscall{syslog(2)}读取传统ASCII行格式（\code{<N>}前缀加换行）。容量常量来自\code{wateros-base-config::klog}。

根\code{Cargo.toml}默认\code{api-v0 + impl-ringbuf + platform-timer + task-api}。\code{platform-timer}提供\code{ts\_nsec\_now}；\code{task-api}提供\code{caller\_id\_now}。bring-up阶段不检查\code{CAP\_SYSLOG}；任意进程可READ/WRITE/CLEAR。
