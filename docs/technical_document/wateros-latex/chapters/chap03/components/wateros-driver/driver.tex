\section{wateros-driver}

\code{wateros-driver}是内核中块设备、字符设备、网络设备与板级探测的统一聚合入口。根crate\code{wateros}通过\code{driver}依赖导出\code{api}、\code{block}、\code{character}、\code{network}四个子系统门面，并由feature三选一挂载\code{active\_impl}平台实现（\code{impl-qemu-riscv64-opensbi}、\code{impl-qemu-loongarch64-virt}或\code{impl-dummy}）。

引导期契约分两步：\code{init\_when\_boot(dtb\_pa)}保存DTB物理基址；MM与帧分配器就绪后由\code{init\_after\_boot}扫描并注册设备，失败仅\code{log::warn}。RISC-V主线经DTB扫描VirtIO-MMIO块/网卡与NS16550 UART；LoongArch主线经PCIe ECAM枚举VirtIO-PCI设备。块设备可选\code{impl-block-cache}写穿LRU包装；网络侧在网卡注册后由\code{network::stack::init}拉起smoltcp，周期性\code{poll\_at\_millis}驱动协议栈。设备注册完成后经\code{wateros-fs}的\code{devfs::refresh}暴露\code{/dev/vblk*}等节点。
