\subsection{driver-impl}

\code{driver-impl}承载平台相关的\code{active\_impl}：三选一feature别名到\code{impl\_qemu\_riscv64\_opensbi}、\code{impl\_qemu\_loongarch64\_virt}或\code{impl\_dummy}。聚合\code{lib.rs}将\code{init\_when\_boot}、\code{physical\_ram\_end\_exclusive}与\code{init\_after\_boot}委托给选中impl；RISC-V与LoongArch另导出\code{uart}子模块供早期串口与\code{klog}使用。

平台impl职责边界：解析DTB或PCI配置空间、实例化各子系统\code{impl-virtio-*}驱动、调用\code{register\_*}、同步\code{devfs}，以及推导物理RAM上界供MM恒等映射。不包含文件系统挂载或socket系统调用逻辑。重复\code{init\_after\_boot}幂等：第二次调用记录\code{WARN}并忽略，避免重复注册。
