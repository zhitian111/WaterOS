\subsubsection{impl-dummy（character）}

\code{character-impl-dummy}不含\code{CharacterDevice}实现或DTB绑定，仅导出占位\code{add}函数维持workspace依赖图。真实UART由平台\code{uart}子模块内联\code{SerialPort}实现并注册；RTC/null由独立\code{impl-*} crate提供。

当根crate未启用\code{impl-null-stub}/\code{impl-rtc-stub}时，\code{register\_builtin\_character\_devices}为空操作，对应feature组合在\code{driver-character/src/lib.rs}中用\code{cfg}分支裁剪。
