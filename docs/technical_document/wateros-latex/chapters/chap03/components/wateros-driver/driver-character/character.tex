\subsection{driver-character}

\code{driver-character}维护字符设备全局注册表与DTB绑定声明（\code{ns16550a}、\code{ns8250}）。\code{is\_uart\_compatible}额外识别\code{snps,dw-apb-uart}供探测使用。\code{SerialPortCharacterDevice}将\code{SerialPort} MMIO辅助trait包装为\code{CharacterDevice}：写路径阻塞至THRE，读路径非阻塞（无数据返回\code{Unsupported}）。

聚合\code{Cargo.toml}默认启用\code{impl-null-stub}与\code{impl-rtc-stub}；\code{register\_builtin\_character\_devices}在平台UART注册后追加RTC与\code{/dev/null}语义设备。RISC-V平台在DTB无UART节点时回退\code{0x1000\_0000} QEMU virt UART0；LoongArch使用固定\code{0x1FE0\_01E0} NS16550（见平台\code{uart}子模块）。devfs按\code{CharacterDeviceKind}区分串口、RTC与null节点；\code{hwclock}相关\code{RTC\_*} ioctl在syscall层对rtc fd分发，而非驱动内实现。
