\subsection{cred-api}

子crate\code{cred-api/api-v0}（包名\code{wateros-cred-api-v0}）定义凭证快照类型与三类trait：\code{CredentialBackend}（生命周期与读取）、\code{CredentialMutation}（per-task ID更新）、\code{AccessCheck}（capability与inode访问）。聚合层以\code{cred::api}再导出全部公共项。

本crate不依赖\code{wateros-task}；\code{TaskId = usize}与调度侧任务ID数值一致但类型解耦，避免循环依赖。
