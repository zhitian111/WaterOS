\subsection{cred-impl}

\code{cred-impl/impl-root}（包名\code{wateros-cred-impl-root}）是默认运行时后端：\code{TaskId -> ProcessCredentials}侧表、线程clone共享owner引用计数、privileged \code{set*id}语义。聚合\code{active\_impl}别名指向本crate；\code{impl-root} feature依赖\code{wateros-task/api-v0}以解析\code{current\_task\_id}。

内部\code{PerTaskCredRegistry}与\code{registry()}静态单例不对外导出；syscall与bring-up仅经聚合门面访问。
