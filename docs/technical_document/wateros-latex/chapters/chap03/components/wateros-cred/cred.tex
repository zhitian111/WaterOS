\section{wateros-cred}

\code{wateros-cred}维护per-task进程凭证（UID/GID/CAP）侧表与生命周期hook，对齐Linux\code{struct cred}子集。用户任务默认以\code{ProcessCredentials::ROOT}启动；\code{fork}复制凭证，线程\code{clone}共享owner引用计数，\code{execve}后更新（首版\code{on\_exec}为no-op）。\code{wateros-task}不依赖本组件；syscall路径与bring-up call site显式调用聚合门面函数。

根\code{Cargo.toml}默认\code{api-v0 + impl-root}。\code{impl-root}启用时导出类型与\code{on\_user\_task\_spawned}、\code{set*id}、\code{has\_cap}等运行时API；仅\code{api-v0}时仅有契约类型，无侧表。syscall层\code{sys/cred.rs}读写聚合门面；\code{may\_access\_inode}尚未接入\code{open}路径。
