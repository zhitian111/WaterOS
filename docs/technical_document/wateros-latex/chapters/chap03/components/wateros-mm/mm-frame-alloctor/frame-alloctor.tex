\subsection{mm-frame-alloctor}

物理帧分配子系统，为页表映射、COW fork、惰性缺页提供以\code{PhysPageNum}为粒度的帧池。聚合 crate \code{wateros-mm-frame-alloctor}再导出\code{api-v0}契约，并按 feature 挂载\code{impl-stack}（默认）或\code{impl-dummy}（桩）。

\code{wateros-mm}聚合层通过\code{mm::frame\_alloctor}暴露\code{init\_frame\_allocator}、\code{frame\_alloc\_result}/\code{frame\_dealloc\_result}、\code{frame\_inc\_ref}/\code{frame\_ref\_count}（COW 引用计数）、\code{frame\_mem\_stats}（供\code{/proc/meminfo}）与\code{GlobalPhysFrameAllocator}零大小适配器。\code{mm-impl}页表 walk 与 COW 路径直接调用帧池全局接口。

默认 feature \code{api-v0}依赖\code{impl-stack}；仅编译契约、不需真实分配时可单独启用\code{impl-dummy}，此时不导出分配符号。
