\section{wateros-base}

\code{wateros-base}提供引导阶段与内核各处共享的薄基础类型：物理/虚拟地址包装、DTB物理地址别名、hart ID、单核\code{UniprocessorSafeCell}同步容器。\code{\#![no\_std]}，无外部依赖，无Cargo feature。数值配置统一放在独立子crate\code{wateros-base-config}（路径\code{base-config/}），避免「双真相」。

根内核以\code{base}别名依赖本crate，以\code{base\_config}别名依赖配置crate。\code{wateros-abi-api-v0}等直接依赖\code{MAX\_SYSCALL\_ARGS}等常量。
