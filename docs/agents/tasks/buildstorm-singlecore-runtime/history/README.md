# BuildStorm 单核运行时优化简报

每个任务完成时在本目录新增 `<NN>-brief.md`，并与该任务实现放在同一个 commit。简报至少包含：

1. 任务状态：接受、拒绝或条件跳过；
2. commit 与修改文件；
3. CodeGraph 查询/影响面；
4. 实际执行的功能命令、输出摘要和日志路径；
5. 性能运行的 `result.json` 路径、SHA-256、guest elapsed 和 host wall；
6. 相对当前最佳记录的决定；
7. 未验证项、剩余风险和下一任务前置条件；
8. 文档同步情况。

低风险批次 01--03 和 signal 批次 05--06 的单项简报允许注明“完整验收待批次任务”，但对应
的 04/07 简报必须关闭这些待验收项。`<500s` 只免除额外性能复跑，不能省略功能结果。
