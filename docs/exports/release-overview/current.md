# 当前阶段项目概述

WaterOS 当前处于从零开始构建的 Rust 内核持续重构与能力收敛阶段。项目已经形成较明确的组件化组织方式，并围绕 `api-v0`、`impl-*` 和聚合导出建立了统一的结构约定。

当前版本最突出的特点包括：

- 已建立 platform、driver、mm、runtime 等核心组件的基础主线。
- 已在 QEMU riscv64 + OpenSBI 路径上组织起启动、日志、堆分配、内存自检、驱动初始化与定时器开启等流程。
- 已明确把不同平台或实现差异收敛到 `impl-*`，并使用 feature 进行选择。
- 文件系统、IPC、任务和 VFS 等方向已经完成目录与职责拆分，但整体仍在持续推进中。

这意味着当前项目已经拥有清晰的架构骨架和一部分核心能力，但仍处于逐步把骨架转化为稳定内核接口与真实实现的阶段。
