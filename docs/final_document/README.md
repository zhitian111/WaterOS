# WaterOS决赛设计文档

[项目首页](../../README.md) · [初赛技术文档](../technical_document/README.md) · [LaTeX 工程](./wateros-latex/README.md)

本目录用于 2026 年操作系统设计赛 OS 内核实现赛道的决赛设计文档。它与
`docs/technical_document/` 中的初赛文档相互独立：初赛文档保留阶段性系统说明，
决赛文档沿用初赛的五章结构，更新SMP、双架构、关键模块和测试验证内容。性能优化方案
和实验数据由单独文档维护，不在本设计文档重复展开。

正式写入文档的结论必须能够追溯到候选提交、构建命令、镜像、日志和结果摘要。
历史运行结果可以用于解释设计过程，但在候选版本完成复验前不得标成最终成绩。
