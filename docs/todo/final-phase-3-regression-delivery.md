## R3-3 性能结果

- Linux 基线和 WaterOS 候选版使用同一评测机与 QEMU 参数。
- CAgent 和 BuildStorm 各运行至少三次，报告每轮结果、中位数和离散程度。
- BuildStorm 同时保留 guest `/proc/uptime` 与宿主墙钟。
- 逐个关闭阶段 2 优化做必要消融，证明主要收益来自哪项修改。
- 不修改计时来源，不改变 judge 标记，不通过预生成目标产物绕过编译。

## R3-4 文档材料

**负责人：A 汇总；B/C 提供各自数据和实现说明**

最终设计文档至少包含：

- 问题现象、复现条件和根因证据；
- 大文件 `read(2)`、文件系统/缓存、task/scheduler、网络等实际保留改动；
- 修改前后编译时间、CAgent 时间和加速比；
- 风险控制、失败方案和未解决限制；
- AI 使用范围、人工确认内容和一键复现步骤；
- 镜像哈希、QEMU 参数、日志索引和 commit 对照。

禁止把临时诊断代码、超大日志、内核二进制、qcow2 overlay 和修改过的评测镜像提交到
仓库。

阻止发布；单项性能未达到预期但功能稳定时，可以删除该优化后发布。
