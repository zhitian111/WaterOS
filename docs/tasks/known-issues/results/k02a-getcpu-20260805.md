# K-02A `getcpu(2)` 实现与验证（2026-08-05）

## 修改

- 注册 Linux generic syscall 号 `168`，接入 kernel syscall dispatch。
- `sys_getcpu` 从平台架构层读取当前逻辑 CPU ID；当前 QEMU 平台均返回 NUMA node 0。
- `cpu` 与 `node` 指针可独立为空；非空用户指针通过统一 user-copy 写入，非法地址返回
  `EFAULT`；与 Linux 一致忽略 `tcache`。

该实现不缓存 CPU ID，因此任务在 syscall 前发生迁移时仍返回实际执行 syscall 的 CPU。
平台 CPU 编号不会泄漏到 syscall API 之外。

## 验证

RISC-V64/OpenSBI 与 LoongArch64/QEMU 均以 8 CPU 启动。测试逐次把线程固定到 CPU
0--7，每架构执行 1,000 轮，共 8,000 次强制迁移，并同时核对 raw `getcpu(2)`、glibc
`sched_getcpu()` 和 affinity 目标：

```text
GETCPU_TEST_PASS online=8 migrations=8000 raw=ok libc=ok node=0 efault=ok
```

此外验证空 `cpu/node` 指针成功、非法非空指针返回 `EFAULT`。`make rv_check`、
`make la_check` 及两架构 pre GDB kernel 构建通过。
