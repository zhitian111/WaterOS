# K-02A 双架构 Fork/COW/Exec 验证（2026-08-05）

## 测试契约

父进程固定在 CPU0，每轮创建一页 `MAP_PRIVATE | MAP_ANONYMOUS` 内存并 fork。子进程
轮流固定到 CPU1--7，先读取继承页以建立远端映射，再通过 pipe 与父进程同步：

1. 父进程写入触发自己的 COW，子进程必须仍读到 fork 时的原值；
2. 子进程写入触发自己的 COW，父进程值必须保持不变；
3. 子进程原地 exec 同一测试 ELF，验证新地址空间中的 affinity、匿名映射和读写；
4. 父进程 wait/reap 后 unmap，进入下一轮。

这覆盖 fork 页表复制、双向 COW、跨 CPU TLB residency、exec 地址空间替换和旧地址
空间回收。任何页串写、旧翻译、exec fault 或非零退出都会立即失败。

## 结果

RISC-V64/OpenSBI 与 LoongArch64/QEMU 均以 8 CPU 运行并完成：

```text
SMP_K02A_FORK_EXEC_PASS iterations=1000 child_cpus=1-7 cow=isolated exec=ok
```

- RISC-V：1,000 轮，22.10 秒，约 64,064 次用户缺页；exit code 0。
- LoongArch：1,000 轮，39.80 秒；exit code 0。
- 两架构均未出现旧映射、父子页泄漏、UAF、panic、signal fault 或任务卡死。

结合此前 RISC-V 10,000 次跨核权限切换、LoongArch 三轮共 30,000 次同 VA 物理页
替换，以及 IPI/timer 双快照，K-02A 的 TLB 与跨进程验收范围已闭合。
