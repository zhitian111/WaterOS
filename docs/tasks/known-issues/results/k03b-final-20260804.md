# K-03B musl-rv Pagefaults 最终复验

## 结果

历史上仅 musl-rv 为 0 的 lmbench Pagefaults 项，在当前内核上已经产生有效结果：

```text
Pagefaults on /var/tmp/XXX: 78.8320 microseconds
K03B libc=glibc pagefault=true
Pagefaults on /var/tmp/XXX: 75.4296 microseconds
K03B libc=musl pagefault=true
K03B_RESULT failed=0
```

musl-rv 不再为 0，且与同轮 glibc-rv 数值处于同一量级。运行没有出现用户 fault kill、
signal frame 失败、panic 或 fatal trap。

## 验证方法

测试直接调用初赛镜像原始 lmbench 二进制和参数，不使用自定义 page-fault microbench：

```sh
./lmbench_all lmdd of=/var/tmp/XXX move=1m fsync=1 print=0
./lmbench_all lat_pagefault -P 1 /var/tmp/XXX
```

glibc 与 musl 使用同一个 `/var/tmp/XXX` 文件布局，分别从 `/glibc` 和 `/musl` 执行。
QEMU 为 RISC-V64 `virt`、OpenSBI、8 CPU、1 GiB；内核目标为
`kernel-rv-ltp-glibc`。同轮内核统计记录约 180050 次用户 page fault，两个命令均正常
返回。
