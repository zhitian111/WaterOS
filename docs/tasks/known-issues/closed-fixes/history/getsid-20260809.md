# `getsid(2)` 实现（2026-08-09）

## 问题

RISC-V64/LoongArch64 的 `__NR_getsid` 为 156，此前未注册，LTP `getsid01/02`
返回 `ENOSYS`。

## 修改

- `os/components/wateros-syscall/syscall-api/api-v0/src/number.rs`：新增
  `GETSID=156`。
- `os/components/wateros-syscall/syscall-impl/impl-kernel/src/syscall_nr_dispatch.rs`：
  分发到 `sys_getsid`。
- `os/components/wateros-syscall/syscall-impl/impl-kernel/src/sys/task/process.rs`：
  `pid=0` 返回当前进程 sid，正数 pid 查询对应进程 sid，不存在返回 `ESRCH`。

## 验证

```text
make check ARCH=rv PROFILE=final
make check ARCH=la PROFILE=final
```

RISC-V LTP 定向日志 `/tmp/getsid-fixed3.log`：

- `getsid01`：父/子进程返回相同 sid，TPASS。
- `getsid02`：不存在 pid 返回 `ESRCH`，TPASS。

LoongArch LTP 定向日志 `/tmp/getsid-la-fixed.log` 同样全部通过。
