# Readonly exec ELF cache 128 MiB capacity experiment

## Evidence

The accepted main has two distinct executable-page caches:

- execve PT_LOAD readonly cache: 16,384 pages / 64 MiB;
- private RX mmap cache: 32,768 pages / 128 MiB.

The RX cache expansion from 64 MiB to 128 MiB produced the largest accepted
single improvement so far: 640.95 s to 534.26 s. Its 300-second diagnostics at
the larger capacity stopped at 27,585 residents with no full bypasses.

The execve ELF cache remains at 64 MiB. Current diagnostics reached 14,362 of
16,384 slots by 300 seconds, while the full compile continues for roughly 230
seconds. Two immediately adjacent experiments clarify the saturation behavior:

- freezing the initial set and bypassing late pages was 10.46 s slower than
  main, proving late pages have useful cross-process reuse;
- replacing the O(16K) victim scan with intrusive O(1) LRU improved only 1.00 s,
  proving victim selection itself is not the major cost.

The remaining hypothesis is capacity churn: useful late rustc/linker/ELF pages
evict useful earlier pages and are reloaded across repeated processes.

## Candidate

Change only `ELF_READONLY_PAGE_CACHE_CAPACITY` from 16,384 to 32,768 pages.
Keep the current key, BTree lookup, true LRU replacement, content-version
rules, refcounts, and RX mmap cache unchanged.

The additional upper bound is 64 MiB of guest physical memory (0.39% of the
16 GiB guest). Unlike adding a generic data cache, these frames have an already
measured high reuse rate and directly avoid page allocation, clear, VFS read,
and VirtIO work on repeated exec faults.

## Verification and acceptance

Run `make check`, `make la_check`, and `make all`; verify both artifacts and
`SCRIPT_BODY_FLAT_BEGIN`. Run one fixed-image RISC-V candidate against the
immediately preceding main result of 553.13 s because the host is currently
slower than the historical 534.26 s. Accept only a complete first result at
least 10 s faster than the adjacent main; reject a regression/noise-sized
change without repetition. Merge only after acceptance and rebuild main.
